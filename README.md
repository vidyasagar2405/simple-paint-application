# 🖌️ OpenCV Paint Application

A simple **Paint Application built with Python & OpenCV**.
This project lets you draw freely, erase, and create shapes like rectangles, circles, and straight lines — with live shape preview and color/thickness controls.

## ✨ Features

* 🖊️ **Pen Mode** – Free drawing
* 🧽 **Eraser Mode** – Erase mistakes easily
* 🔲 **Shapes** – Rectangle, Circle, and Line with live preview
* 🎚️ **Trackbars** – Control RGB colors & thickness
* 💾 **Save Option** – Save your canvas as an image
* ⬜ **Clear Canvas** – Reset anytime

## 🛠️ Technologies Used

* Python 🐍
* OpenCV (cv2)

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/opencv-paint-app.git
   cd opencv-paint-app
   ```
2. Install dependencies:

   ```bash
   pip install opencv-python numpy
   ```
3. Run the app:

   ```bash
   python paint_app.py
   ```

## 🎮 Controls

* **Q** → Quit
* **P** → Pen Mode
* **E** → Eraser Mode
* **S** → Save canvas
* **D** → Clear canvas
* **Click Shapes (right sidebar)** → Rectangle / Circle / Line
